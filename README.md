# JARVIS AI — Android

Assistente pessoal para Android, desenvolvida em Kotlin.

## Projeto
O aplicativo Android está em `jarvis-android/`. A primeira versão contém interface nativa, reconhecimento de fala em português, síntese de voz e comandos locais para abrir aplicativos e pesquisar na web.

## Compilação
O workflow GitHub Actions em `.github/workflows/jarvis-android-build.yml` compila o APK de depuração e publica o artefato na execução.

## Estado
Versão inicial em desenvolvimento. A palavra de ativação contínua "Jarvis", execução confiável com tela apagada e integração com modelo de IA ainda precisam ser implementadas e testadas.

## Segurança
Não armazene chaves de API ou credenciais no aplicativo ou neste repositório.
